# TZ.md — САЙТ-ПОРТФОЛИО МАРИИ КОРЕНЕВОЙ
## 1. Задача проекта
Создать современный двуязычный сайт-портфолио Марии Кореневой. Сайт является реальным рабочим портфолио, способом показать направления работы и примеры решений, дать потенциальному клиенту возможность быстро понять, с какими задачами можно обратиться к Марии, и связаться с ней.
Визуальный референс сайта — файл `Черновик портфолио.html`, находящийся в проекте. Использовать его как образец дизайна, композиции, цветовой гаммы, типографики, размеров элементов и общего визуального стиля. Не создавать новый дизайн вместо референса.
Утвержденные фотографии находятся в отдельных файлах: `maria-hero.jpg` — фото с ноутбуком для Hero; `maria-about.jpg` — фото без ноутбука для секции «Обо мне» / `About Me`.
Сайт должен быть технически чистым, адаптивным и удобным для дальнейшего расширения.
## 2. Главный принцип
Посетитель не обязан разбираться в технологиях и заранее знать, нужен ему сайт, бот, ИИ-помощник или онлайн-инструмент. Он может просто рассказать, что хочет сделать, изменить, упростить или ускорить. Мария подбирает подходящее решение и реализует его с помощью ИИ.
Главный акцент — не на технологиях самих по себе, а на решении реальной задачи человека или бизнеса. Не позиционировать Марию исключительно как веб-разработчика, программиста или AI-разработчика.
## 3. Языки
Сайт сразу создается на русском и английском языках. Русский — язык по умолчанию.
В шапке использовать компактный переключатель `RU | EN`.
Использовать одну структуру сайта и централизованные данные переводов. Не создавать две независимые копии сайта.
При переключении языка должны меняться все тексты интерфейса и контента. Все RU- и EN-тексты приведены в этом ТЗ. Не переводить, не переписывать и не улучшать их самостоятельно.
## 4. Визуальный стиль
Сохранять визуальный стиль файла `Черновик портфолио.html`: темный графитовый/почти черный фон, глубокое синее градиентное свечение, молочный основной текст, приглушенный серый вторичный текст, персиковый акцент `#E1AA91`.
Не использовать зеленые, фиолетовые, радужные и случайные дополнительные акценты.
Общее ощущение: современно, профессионально, технологично, спокойно, без визуального перегруза.
Основной шрифт — `Manrope`. Для поддерживающего текста Hero допустим `Inter`.
## 5. Анимация
Использовать спокойную scroll-reveal анимацию: `opacity: 0 → 1` и `translateY → 0`. Ориентир для desktop — около `24px / 0.7s`, для mobile — около `48px / 0.8s`. Карточки могут появляться с небольшим последовательным интервалом.
Первый экран не скрывать при первоначальной загрузке. Контент должен оставаться видимым, если JavaScript не выполнился. Использовать progressive enhancement: скрывать элементы для reveal только после успешной инициализации JavaScript. Учитывать `prefers-reduced-motion`.
Светящийся или бегущий контур кнопок сейчас не создавать.

## 17. Что не создавать
В текущей версии сайта полностью отсутствует предложение обучения. Не создавать разделы `Обучение` / `Training`, соответствующие пункты меню, шестую карточку про самостоятельное создание инструментов с помощью ИИ, предложения обучающих программ и формулировки `научу`, `обучаю`, `обучение` как описание услуги, а также их английские аналоги.

В EN использовать только: `I use AI to create websites, personal assistants, bots, and online tools.`
Также пока не добавлять ИИ-бота, AI-аватара, отзывы, вымышленные кейсы, вымышленные сертификаты, новые услуги, неподтвержденные достижения, новые цифры результатов, цены и прием платежей.
## 18. Будущее расширение
Архитектура должна позволять без перестройки готового сайта позднее подключить ИИ-бота, изменить действие основных CTA с перехода к контактам на запуск бота, добавлять реальные сайты, ИИ-помощников, онлайн-инструменты, ботов, кейсы по позиционированию, сертификаты и видео, корректировать тексты после кастдевов и при необходимости добавлять новые языки.
Не создавать сейчас пустые блоки под будущие функции.
## 19. Адаптивность
Сайт должен полноценно работать на desktop, tablet и mobile.
Не допускать горизонтального скролла, обрезанного текста, выхода кнопок за экран, наложения элементов, обрезки фотографий, недоступного меню и исчезновения контента из-за анимации.
Все интерактивные элементы на mobile должны иметь удобную область нажатия.

## 21. Порядок разработки
Это ТЗ описывает весь будущий сайт, но НЕ означает, что его нужно создавать целиком за один запрос. Сначала полностью прочитать `TZ.md` и `SKILL.md`, затем изучить файл `Черновик портфолио.html`, чтобы понимать будущую архитектуру, содержание и визуальный стиль.
Разрабатывать сайт строго поэтапно.
Этап 1: создать технический каркас проекта, Header, Hero, RU/EN, mobile и базовую scroll-reveal механику. После выполнения остановиться.
Следующие этапы выполнять только по отдельной команде пользователя: `Чем могу помочь` → `Примеры решений` → `Результаты в цифрах` → `Как я работаю` → `Обо мне` → `Сертификаты` → финальный CTA → `Контакты` → Footer → финальная проверка.
Каждый новый раздел сразу создавать в RU и EN и сразу адаптировать под desktop/mobile.
После утверждения раздел считать зафиксированным. При работе над следующим этапом не менять без команды уже утвержденные тексты, дизайн, фотографии, цвета, размеры и поведение предыдущих разделов.
## 22. Итоговая логика сайта
Посетитель должен быстро понять: `Мне не нужно разбираться в ИИ, сайтах, ботах и других технологиях. Я могу рассказать Марии, какую задачу хочу решить, а она предложит подходящий вариант и реализует его.`
Сайт показывает сочетание трех направлений: `Психология + наука + ИИ`.
Главный акцент — практический результат для клиента: экономия времени, сокращение части расходов, решение рабочих задач, создание полезных инструментов и понятный путь от идеи до готового результата.
